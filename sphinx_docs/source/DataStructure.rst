DataStructure
=========================


=========================
Description
=========================
The data structures used in the Austenite Calculator are shown below.

SUPERSEEDS README-Developer.txt

*DataFrame* and *(Series)* are pandas objects. *Array* is a numpy array.  All other datatypes are python objects.

Data structures are described as a bulleted list.  Indentation implies the data structure is contained as part of the less indented item listed above.

**Key Name**	*(Datatype)*	Explanation  **Open Question**

**Submission**
=========================

**Submission**	*(Dictionary)*	Container for all the items computed
 * **Phase_Info**	*(Dictionary)*	Container for phase information
 
    * **Interaction_Parameters** *(Dictionary)*	Values from Crystallites Illumininated json file.  Keys of:

        * **<phase names>** from the entered CIF file names with a (List) of values of particulate size *(Float)*, number of particles *(Float)*, rocking angle *(Float)*, texture corrections *(List)* (optional)
        * **beam_shape** *(String)*
        * **beam_size** *(Float)*
        * **raster_x** *(Float)*
        * **raster_y** *(Float)*
        * **sample_displacement** *(Float)*
        * **L** *(Float)*
        * **W_F** *(Float)*
        * **H_F** *(Float)*
        * **H_R** *(Float)*
        
    * **Atomic_Masses** *(Series)* Values from 'atomic_masses_dict' for rows of elements listed **Shouldn't there be two lists?**
    
    * **Unit_Cell**		*(DataFrame)* Rows for each cif file names with the following columns:

        * **scattering_dict**  *(Nested List)* List for each element given in the cif file with list containing element symbol *(String)*, f' value *(Float)*, f'' value *(Float)*, mu value *(Float)*, and number of atoms per cell *(Float)*.  These values come from GSAS-II **CITE**
        * **elem_fractions_dict** *(List)* Atomic fractions of each element *(Float)* (site occupancy). Order of list is the same as in *scattering_dict*
        * **average_scattering_dict** *(List)* Weighted summation of f' value *(Float)*, f'' value *(Float)*, and mu value *(Float)* for all elements in the phase based on atomic fraction.
        * **unit_cell_volume_CIF** *(Float)* The volume of each unit cell, from the CIF file. Units of cubic angstroms. **Should we use the fitted value or compare?**
        * **unit_cell_mass_CIF** *(Float)* Weighted summation of atomic mass for all elements in the phase based on atomic fraction.

    * **Phase_list**  *(Array)* Array of phases, without the .cif file extension **From CIF filename or CIF file header?**

 * **File_Paths**	*(Dictionary)* Container for folder paths and file names. Keys of:

   * **Data_Directory**		*(String)*
   * **Working_Directory**	*(String)*
   * **Cif_Filenames**		*(List)*
   * **Diffraction_Filenames** 	*(List)*
   * **Instrument_Filename**	*(String)*
   * **JSON_Filename**		*(String)*
   * **Dataset_name**		*(List)*

 * **Version**	*(DataFrame)*	Container for version information for the Austenite Calculator.  Rows of:

    * **Git URL** *(String)* Austenite Calculator Git URL
    * **Git Branch** *(String)* Austenite Calculator Git Branch name
    * **Git Commit Hash** *(String)* Austenite Calculator Git commit ID
    * **Git Commit Oneline** *(String)* Austenite Calculator Git short commit ID and commit comment
    * **GSAS_version**  *(String)* GSAS-II version number

 * **Dataset_<#>** *(Dictionary)* Container for each diffraction dataset provided and analyzed. Keys of:
 
   * **X_Range** *(List)* List of the 2-theta min and max values.
   * **Flags** 		*(DataFrame)* Collected comments and flags for the user to consider. Columns of:

        * **Value** *(object)* Numeric or string value extracted to flag.
        * **Unit** *(String)* Units for the value, or NaN if not applicable.
        * **Source** *(String)* Location in the code the flag was raised.
        * **Flags** *(String)* Text describing the concern flagged.
        * **Suggestions** *(String)* Suggested mitigation options.

   * **Le_Bail_Data** *(Dictionary)* Diffraction dataset fit data using Reitveld refinement with Le Bail extraction to allow for arbitrary intensities. This data is generated by GSAS-II and uses their data conventions, see **CITE documentation** for more information.  Keys of:
        * **Reflection Lists**
        * **Limits**
        * **data**
        * **Index Peak List**
        * **Comments**
        * **Unit Cells List**
        * **Sample Parameters**
        * **Peak List**
        * **Background**
        * **Instrument Parameters**
        
   * **Le_Bail_Scale** *(Float)* Histogram (GSAS-II name for diffraction data) scale value from LeBail fit, used for calculating theoretical intensities to get approximatly similar scales for intensity.
   * **Theoretical_Intensities** *(DataFrame)* Calculated theoretical intenisities with rows for each peak in the dataset and phase. Columns of:
        * **h_TI** *(Float)* 'h' from crystal plane 'hkl'
        * **k_TI** *(Float)* 'k' from crystal plane 'hkl'
        * **l_TI** *(Float)* 'l' from crystal plane 'hkl'
        * **mul_TI**  *(Float)* Multiplicity for crystal plane 'hkl'
        * **pos_TI**  *(Float)* 2-theta position for crystal plane 'hkl'
        * **F_calc_sq_TI**  *(Float)* Caculated scattering factor F^2 for crystal plane 'hkl' and elemental composition provided in CIF file.
        * **I_corr_TI**   *(Float)* Aggregated intensity correction values for crystal plane 'hkl'.
        * **R_TI**   *(Float)* Caculated theoretical intensity for crystal plane 'hkl'
        * **Phase_TI**  *(Float)* Cif file name for each crystal plane 'hkl'.
        * **Texture Correction**  *(Float)* Texture correction value if applied to theoretical intensity.  Default value of 1 (no texture correction) if none are provied in crystallites illuminated JSON file.
   
   * **Peak_Fit_Data** *(Dictionary)* Diffraction dataset fit data using individual peak fit extractions for each peak using the GSAS-II Peak Fit function. This data is generated by GSAS-II and uses their data conventions, see **CITE documentation** for more information.  Keys of:
        * **Reflection Lists**
        * **Limits**
        * **data**
        * **Index Peak List**
        * **Comments**
        * **Unit Cells List**
        * **Sample Parameters**
        * **Peak List**
        * **Background**
        * **Instrument Parameters**
        * **Peak Fit Result**
        * **Peak Fit Sig**
        * **Peak Fit Rvals**
        
   * **Gaussian_Data** *(Dictionary)* Diffraction dataset fit data using individual peak fit with a single Gaussian peak.  Dictionary has a single key 'data' that containts a *(Nested List)* with the first column [0] the 2-theta position and second column [1] the fitted intensity. **Still in development**.
   * **Gaussian_Peaks**  *(DataFrame)* Calculated Gaussian peak intenisities with rows for each peak in the dataset and phase. Also includes some of the Le Bail fitting values for reference and comparision. Columns of:
        * **pos_LB** *(Float)*  2-theta position value for crystal plane 'hkl' from Le Bail fit.
        * **sig_LB** *(Float)* Gaussian width (sigma in GSAS-II) peak fit component value from the Le Bail fit. Described in centi-degrees.
        * **int_LB** *(Float)* Integrated intensity value from the Le Bail fit.
        * **pos_G**  *(Float)* 2-theta position for crystal plane 'hkl' from the Gaussian fit.
        * **sig_G** *(Float)* Gaussian width from the Gaussian fit. Described in centi-degrees.
        * **int_G** *(Float)* Integrated intensity value from the Gaussian fit.
        * **int_G_total** *(Float)* Integrated intensity value from a trapezoidal rule integration over a window of the peak width. Uses the total number of counts.
        * **int_G_bg** *(Float)* Integrated intensity value from a trapezoidal rule integration over a window of the peak width. Fits only the background over the window.
        * **int_G_TR** *(Float)* Integrated intensity value from a trapezoidal rule integration over a window of the peak width. This value is the total - background, and should only represent peak height.
        * **fit_success_G**  *(Boolean)* True if the Gaussian peak fit function was able to complete successfully. If False, all _G columms are set to NaN.  **A 'True' value does not currently imply the values are reasonable**
   * **Merged_Peaks**   *(DataFrame)* Container for aggregated peak data
         
         * **pos_fix** *(Float)* 2-theta position value for crystal plane 'hkl' from the Peak Fit fit.
         * **int_fit** *(Float)* Integrated intensity value from the from the Peak Fit fit.
         * **sig_fit** *(Float)* Gaussian width (sigma in GSAS-II) peak fit component value from the Peak Fit fit. Described in centi-degrees.
         * **gam_fit** *(Float)* Lorentzian width (gamma in GSAS-II) peak fit component value from the Peak Fit fit. Described in centi-degrees.
         
         * **Peak_Fit_Success**
         
         * **u_pos_fit** *(Float)* Uncertainty in the 2-theta position value for crystal plane 'hkl' based on the Peak Fit fit.
         * **u_int_fit** *(Float)* Uncertainty in the integrated intensity value for crystal plane 'hkl' based on the Peak Fit fit.
         
         * **back_int_bound**
         * **signal_to_noise**

         * **mul_TI**  *(Float)* Multiplicity for crystal plane 'hkl'
         * **pos_TI**  *(Float)* 2-theta position for crystal plane 'hkl'
         * **F_calc_sq_TI**  *(Float)* Caculated scattering factor F^2 for crystal plane 'hkl' and elemental composition provided in CIF file.
         * **I_corr_TI**   *(Float)* Aggregated intensity correction values for crystal plane 'hkl'.
         * **R_TI**   *(Float)* Caculated theoretical intensity for crystal plane 'hkl'
         * **Phase_TI**  *(Float)* Cif file name for each crystal plane 'hkl'.
         * **Texture Correction**  *(Float)* Texture correction value if applied to theoretical intensity.  Default value of 1 (no texture correction) if none are provied in crystallites illuminated JSON file.
